# OSINT Fusion

An open-source intelligence (OSINT) gathering and analysis workspace.

## Features
- Multi-source intelligence aggregation
- Domain, IP, and handle investigations
- Interactive data visualization & reporting

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/RJ07CyberSecurity/OSINT-Fusion.git
   cd OSINT-Fusion
   ```
